## コマンドラインリファレンス

`pdf-kozou-core` は Tauri サイドカーとして動作する処理エンジンです。
直接実行することでコマンドラインツールとしても使用できます。

```
pdf-kozou-core <SUBCOMMAND> [OPTIONS]
```

---

### `info` — PDF 基本情報の取得

```
pdf-kozou-core info [OPTIONS] <PATH>
```

| 引数・オプション   | 説明                                                                 |
| ------------------ | -------------------------------------------------------------------- |
| `<PATH>`           | 入力ファイルパス（PDF / EPUB / DOCX / XPS / CBZ / 画像 等）          |
| `--fonts`          | 埋め込みフォント情報も取得する（PDF のみ有効）                       |
| `--convert`        | 非 PDF ファイルを自動変換してから正確な情報を取得する                |
| `--layout-w <pt>`  | リフロー可能文書のレイアウト幅（`--convert` 時に使用、省略時 450pt） |
| `--layout-h <pt>`  | リフロー可能文書のレイアウト高さ（省略時 600pt）                     |
| `--layout-em <pt>` | リフロー可能文書のフォントサイズ（省略時 12pt）                      |

---

### `render` — PDF ページを画像にレンダリング

```
pdf-kozou-core render [OPTIONS] <PATH>
```

| 引数・オプション         | 説明                                                                                                                                             |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| `<PATH>`                 | 入力 PDF ファイルパス                                                                                                                            |
| `--page <指定>`          | 出力ページ指定（1始まり）。省略時は `--out-dir` が必須で全ページ出力。`1` 単ページ / `1-3` 範囲 / `1,3,5` 複数 / `1-3,5,7` 混在 / `all` 全ページ |
| `--dpi <dpi>`            | 解像度（デフォルト: `144`）                                                                                                                      |
| `--format <fmt>`         | 出力フォーマット: `jpeg` \| `png` \| `svg`（デフォルト: `jpeg`）                                                                                 |
| `--quality <0-100>`      | JPEG クオリティ（デフォルト: `85`）                                                                                                              |
| `--output <path>`        | 単ページ出力先ファイルパス（`--page` で単ページ指定時のみ有効）                                                                                  |
| `--out-dir <dir>`        | ファイル出力先ディレクトリ（`--page` 省略時に必須）                                                                                              |
| `--name-prefix <prefix>` | ファイル名プレフィックス。末尾が数字なら連番はその続きから。省略時は入力ファイルのステム + `_p`（例: `input_p001.jpg`）                          |
| `--start-number <n>`     | 連番開始番号（省略時は `--name-prefix` 末尾の数字、またはデフォルト 1）                                                                          |
| `--layout-w <pt>`        | リフロー可能文書のレイアウト幅（省略時 450pt）                                                                                                   |
| `--layout-h <pt>`        | リフロー可能文書のレイアウト高さ（省略時 600pt）                                                                                                 |
| `--layout-em <pt>`       | リフロー可能文書のフォントサイズ（省略時 12pt）                                                                                                  |

---

### `trim` — PDF のトリミング（CropBox 設定）

```
pdf-kozou-core trim [OPTIONS] <INPUT> <OUTPUT>
```

| 引数・オプション   | 説明                                                                     |
| ------------------ | ------------------------------------------------------------------------ |
| `<INPUT>`          | 入力 PDF                                                                 |
| `<OUTPUT>`         | 出力 PDF                                                                 |
| `--left <値>`      | 左余白（デフォルト: `0`）                                                |
| `--right <値>`     | 右余白（デフォルト: `0`）                                                |
| `--top <値>`       | 上余白（デフォルト: `0`）                                                |
| `--bottom <値>`    | 下余白（デフォルト: `0`）                                                |
| `--unit <単位>`    | 単位: `mm`（デフォルト）\| `pt` \| `cm` \| `in`                          |
| `--pages <指定>`   | トリミング対象ページ（例: `1,3,5-10,all,odd,even`）。省略時は全ページ。  |
| `--exclude <指定>` | 除外ページ。`--pages` で指定した範囲からトリミングを除外。               |
| `--extract <指定>` | 抽出ページ。トリミングと無関係に特定ページのみ残す。省略時はすべて残す。 |

---

### `compress` — PDF の圧縮・最適化

```
pdf-kozou-core compress [OPTIONS] <INPUT> <OUTPUT>
```

| 引数・オプション              | 説明                                                                                                                                                     |
| ----------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `<INPUT>`                     | 入力 PDF                                                                                                                                                 |
| `<OUTPUT>`                    | 出力 PDF                                                                                                                                                 |
| `--rewrite`                   | DocumentWriter で全ページ再描画して再圧縮（gs 相当の高圧縮、ベクター・フォント保持）。⚠️ Type3 フォントを含む PDF は安全な通常圧縮に自動フォールバック。 |
| `--rewrite-options <opts>`    | `--rewrite` 時の追加オプション（MuPDF オプション文字列）                                                                                                 |
| `--preset <名前>`             | 圧縮プリセット: `light` \| `standard`（デフォルト）\| `aggressive` \| `maximum`。⚠️ `maximum` は埋め込みフォントに影響する場合あり。                     |
| `--no-compress-images`        | 画像を圧縮しない（プリセットより優先）                                                                                                                   |
| `--no-compress-fonts`         | フォントストリームを圧縮しない（プリセットより優先）                                                                                                     |
| `--gc <0-4>`                  | ガベージコレクションレベル（プリセットより優先）                                                                                                         |
| `--clean`                     | コンテンツストリーム再構築を有効化（プリセットより優先）                                                                                                 |
| `--sanitize`                  | ストリーム再解釈を有効化（⚠️ フォントリスクあり、プリセットより優先）                                                                                    |
| `--font-subset`               | フォントサブセット化を有効化（⚠️ CJK/多言語フォントで不安定な場合あり）                                                                                  |
| `--object-stream`             | 未使用埋め込みフォントを除去                                                                                                                             |
| `--merge-fonts`               | フォントを統合                                                                                                                                           |
| `--rasterize-dpi <dpi>`       | Type3 フォント検出時のラスタライズ DPI（`--rewrite` 時のみ有効、デフォルト 150）                                                                         |
| `--rasterize-quality <0-100>` | Type3 フォント検出時の JPEG 品質（`--rewrite` 時のみ有効、デフォルト 85）                                                                                |

---

### `rasterize` — PDF を全ページ画像化して PDF に再出力

```
pdf-kozou-core rasterize [OPTIONS] <INPUT> <OUTPUT>
```

> ⚠️ この操作はページ全体を画像に変換します。テキスト選択・検索・コピーが失われます。Type3 フォントを含む PDF でも処理できます。通常の圧縮が目的なら `compress` または `compress --rewrite` を使用してください。

| 引数・オプション    | 説明                                                    |
| ------------------- | ------------------------------------------------------- |
| `<INPUT>`           | 入力 PDF                                                |
| `<OUTPUT>`          | 出力 PDF                                                |
| `--dpi <dpi>`       | 解像度（デフォルト: `150`）                             |
| `--quality <0-100>` | JPEG 品質（デフォルト: `85`）                           |
| `--page <指定>`     | ページ指定（`1-3,5` 形式、1ベース）。省略時は全ページ。 |
| `--png`             | PNG 埋め込みで画像 PDF を生成（可逆・無劣化）           |

---

### `split` — PDF の分割

```
pdf-kozou-core split [OPTIONS] <INPUT> <OUT_DIR>
```

| 引数・オプション    | 説明                                               |
| ------------------- | -------------------------------------------------- |
| `<INPUT>`           | 入力 PDF                                           |
| `<OUT_DIR>`         | 出力ディレクトリ                                   |
| `--prefix <prefix>` | 出力ファイルのプレフィックス（デフォルト: `page`） |
| `--every <n>`       | N ページごとに分割（省略時は 1 ページずつ）        |
| `--ranges <指定>`   | ページ範囲で分割（例: `1-3,4-6,7-10`）             |

---

### `merge` — PDF の結合

```
pdf-kozou-core merge --output <OUTPUT> <INPUTS>...
```

| 引数・オプション                | 説明                         |
| ------------------------------- | ---------------------------- |
| `<INPUTS>...`                   | 結合するファイル（複数指定） |
| `--output <path>` / `-o <path>` | 出力 PDF                     |

---

### `rotate` — PDF ページの回転

```
pdf-kozou-core rotate [OPTIONS] <INPUT> <OUTPUT>
```

| 引数・オプション       | 説明                                                                                                        |
| ---------------------- | ----------------------------------------------------------------------------------------------------------- |
| `<INPUT>`              | 入力 PDF                                                                                                    |
| `<OUTPUT>`             | 出力 PDF                                                                                                    |
| `--angle <度>`         | 全ページ共通の回転角度: `0` \| `90` \| `180` \| `270`。`--page-angles` と併用可（`--page-angles` が優先）。 |
| `--pages <指定>`       | 対象ページ（例: `1,3,5`）。省略時は全ページ。`--angle` と組み合わせて使用。                                 |
| `--page-angles <指定>` | ページ個別の回転角度（例: `1:90,2:180,3:270`）。`--angle` より優先。                                        |

---

### `convert` — 非 PDF ファイルを PDF に変換

```
pdf-kozou-core convert [OPTIONS] <INPUT> <OUTPUT>
```

対応形式: EPUB / DOCX / XPS / HTML / 画像 等

| 引数・オプション   | 説明                                                  |
| ------------------ | ----------------------------------------------------- |
| `<INPUT>`          | 入力ファイルパス                                      |
| `<OUTPUT>`         | 出力 PDF ファイルパス                                 |
| `--layout-w <pt>`  | リフロー可能文書のレイアウト幅（デフォルト: `450`）   |
| `--layout-h <pt>`  | リフロー可能文書のレイアウト高さ（デフォルト: `600`） |
| `--layout-em <pt>` | ベースフォントサイズ（デフォルト: `12`）              |

---

### `json` — Tauri サイドカーモード（stdin JSON）

```
pdf-kozou-core json
```

stdin から JSON リクエストを 1 行ずつ受け取り、JSON レスポンスを stdout に返します。GUI（Tauri）との通信に使用するモードです。通常は直接使用しません。
